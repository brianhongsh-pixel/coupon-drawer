# 쿠폰서랍 — 기프티콘 자동 정리 앱

카톡에서 받은 기프티콘을 저장하거나, 캡처하거나, 사진으로 찍으면 **알아서 읽고 등록**해서
유효기간 순으로 정리해 주는 안드로이드 앱입니다.

## 설치 (안드로이드)
휴대폰에서 이 저장소의 **Releases → 최신 버전 → `coupon-drawer.apk`** 를 내려받아 설치하세요.
처음 설치할 때 '출처를 알 수 없는 앱 설치' 허용이 필요합니다.

## 기능
- 새 기프티콘 자동 감지: 사진 폴더에 쿠폰 이미지가 생기면 바코드·유효기간·교환처·상품명을 읽어 자동 등록
- 카톡/갤러리에서 '공유 → 쿠폰서랍'으로 바로 등록, 카메라로 찍어서 등록
- 중복·쿠폰 아닌 사진 자동 제외, 못 읽은 칸은 '확인 필요'로 표시
- D-day 정렬, 만료 3일 전·전날·당일 알림, 금액권 잔액 관리, 바코드 크게 보기(밝기 최대)
- 모든 인식은 휴대폰 안에서 처리(Google ML Kit) — 사진이 외부로 전송되지 않음

## 구조
- `web/` — 앱 화면 (아이폰·PC는 웹 버전으로 사용 가능)
- `android/` — 안드로이드 앱 (사진 감시, 인식, 알림)
- `.github/workflows/build.yml` — 올리면 자동으로 APK를 만들어 Releases에 게시
