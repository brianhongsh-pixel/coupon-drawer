# 쿠폰서랍 — 기프티콘 자동 정리 앱

카톡에서 받은 기프티콘을 저장하거나, 캡처하거나, 사진으로 찍으면 **알아서 읽고 등록**해서
유효기간 순으로 정리해 주는 앱입니다. 안드로이드 앱과 웹 버전(PWA)이 있어요.

## 설치
- **안드로이드**: Releases → 최신 버전 → `coupon-drawer.apk` 를 내려받아 설치하세요.
  처음 설치할 때 '출처를 알 수 없는 앱 설치' 허용이 필요합니다.
- **아이폰 · PC**: 웹 버전 <https://brianhongsh-pixel.github.io/coupon-drawer/>
  (저장소 Settings → Pages 를 켜면 열립니다. 사파리/크롬에서 '홈 화면에 추가'하면 앱처럼 써요.)

## 기능
- 새 기프티콘 자동 감지: 사진 폴더에 쿠폰 이미지가 생기면 바코드·유효기간·교환처·상품명을 읽어 자동 등록
- 카톡/갤러리에서 '공유 → 쿠폰서랍'으로 바로 등록, 카메라로 찍어서 등록
- 중복·쿠폰 아닌 사진 자동 제외, 못 읽은 칸은 '확인 필요'로 표시
- **유효기간 임박 알림**: 7일 전 · 3일 전 · 전날 · 당일 중 원하는 시점을 골라서 알림.
  같은 날 만료되는 쿠폰은 알림 하나로 모아서 보내고, 안드로이드는 매일 오전 9시에 알려 줘요.
- **곧 만료 보기**: 화면 위 배너나 '곧 만료' 칩을 누르면 7일 안에 만료되는 쿠폰만 모아 볼 수 있어요.
  알림을 눌러 앱을 열면 그 목록으로 바로 들어갑니다.
- D-day 정렬, 금액권 잔액 관리, 바코드 크게 보기(밝기 최대), 캘린더 알림 추가
- 모든 인식은 기기 안에서 처리(안드로이드는 Google ML Kit, 웹은 내려받은 OCR 엔진) — 사진이 외부로 전송되지 않음

## 구조
- `source.zip` — 앱 소스. 안에 `web/`(앱 화면, 안드로이드 앱 안에도 그대로 들어감)과
  `android/`(안드로이드 앱: 사진 감시·인식·알림)가 들어 있어요. 빌드는 이 zip을 풀어서 합니다.
- `.github/workflows/build.yml` — push하면 APK를 만들어 Releases에 올리고, 웹 버전을 GitHub Pages에 배포

## 소스 고치기
`source.zip` 안의 파일을 고쳐서 다시 올리면 됩니다.
(`web/`·`android/` 폴더를 zip 대신 그대로 올리는 방식으로 바꾸려면 워크플로의 "소스 풀기"
단계만 손보면 돼요. 그렇게 바꾸면 GitHub에서 파일별 수정·diff 확인이 가능해집니다.)
